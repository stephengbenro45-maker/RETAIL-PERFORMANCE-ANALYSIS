# RETAIL-PERFORMANCE-ANALYSIS
An end-to-end retail analysis project using Advanced SQL (CTEs &amp; Window Functions) for data engineering and Power BI for executive-level reporting. Answered 20+ complex business questions through robust data modeling.


 Retail Performance Executive Overview 📊

## 📌 Project Overview
This project is an end-to-end data analysis solution designed to track key retail metrics and provide executive-level insights. It transitions from raw data cleaning in SQL to a high-fidelity interactive dashboard in Power BI.

## 🛠️ Technical Toolkit
- *SQL Server (T-SQL):* Data Cleaning, CTEs, Window Functions, and Schema Mapping.
- *Power BI:* Data Modeling (Star Schema), DAX Measures, and UI/UX Design.
- *Excel:* Initial data sourcing and validation.

## 🧠 Business Questions Answered
I used advanced SQL queries to solve 20+ business problems, including:
- *Revenue Analysis:* What is our total revenue and AOV (Average Order Value)?
- *Geographic Growth:* Which cities are driving 80% of our growth?
- *Customer Insights:* What is the Customer Lifetime Value (LTV) across different segments?
- *Operational Health:* How do return rates and cancelled orders impact our net profit margins?

## 📐 Data Architecture (The "Engine")
I implemented a *Star Schema* to ensure fast report performance and data integrity. By separating Fact tables (Sales) from Dimension tables (Products, Customers, Dates, and Geography), the model is scalable and efficient.
